03

Release interlocks

Controller จะไม่เปลี่ยน traffic จนกว่า route และ candidate ผ่านเงื่อนไข

  1. Envoy control planeกำลังตรวจสอบ config dump
  2. Candidate releaseกำลังตรวจสอบ health probe
  3. Atomic publicationเขียน temporary file แล้ว rename ใน filesystem เดียวกัน
  4. Failover alertsกำลังตรวจสอบ Alertmanager
