    Analysis gate

    Controller อ่าน upstream_rq_completed และ upstream_rq_5xx ของแต่ละ cluster จาก Envoy ทุก 2 วินาที

    2. Canary health probeกำลังตรวจสอบ
    3. จำนวน samplesกำลังตรวจสอบ
    4. Canary 5xx rateกำลังตรวจสอบ
